# M02. Классическое ML

🎯 **Цель модуля:** освоить понятия, без которых нельзя честно оценить ни одну модель, в том числе LLM:
валидацию и утечки, метрики и пороги, калибровку. Попутно — линейные модели, градиентный бустинг
как сильнейший метод для таблиц и кластеризацию эмбеддингов.

⏱ ~8 часов · **Пререквизиты:** M01 (градиенты, softmax, кросс-энтропия, SVD).

## Как запустить

```bash
make native M=02   # нативно на Mac
make lab M=02      # в Docker → http://localhost:8888
make test M=02     # проверка упражнений
```

Датасеты Adult (0,6 МБ) и RuReviews (22 МБ) скачиваются при первом запуске в `data/`.
Урок 4 обращается к модели эмбеддингов, ответ записан в кассету.
