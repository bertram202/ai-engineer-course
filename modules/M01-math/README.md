# M01. Математика для LLM

🎯 **Цель модуля:** освежить ровно ту математику, на которой стоят LLM, — и сразу увидеть её
в работе: на настоящих эмбеддингах и настоящих вероятностях токенов от моделей курса.

⏱ ~6 часов · **Пререквизиты:** M00, школьная алгебра, производная. Если уверенно отвечаете на
[вопросы для самопроверки](theory/theory.qmd#вопросы-для-самопроверки), модуль можно пролистать.

## Как запустить

```bash
make native M=01   # нативно на Mac
make lab M=01      # в Docker → http://localhost:8888
make test M=01     # проверка упражнений
```

Урок 1 обращается к модели эмбеддингов, урок 3 — к `main` и `local`. Ответы записаны в кассеты,
поэтому уроки выполняются и без моделей. Чтобы увидеть ответы своих моделей, измените промпт
или запустите `LLM_CACHE=refresh make check M=01`.
