# M04. NLP и Hugging Face

🎯 **Цель модуля:** понять, как текст превращается в числа — от мешка слов до токенов и контекстных
эмбеддингов, — освоить экосистему Hugging Face и научиться выбирать между дообучением маленькой
модели и промптом к LLM по замерам, а не по моде.

⏱ ~6 часов · **Пререквизиты:** M02 (метрики, валидация), M03 (PyTorch, эмбеддинги).

## Как запустить

```bash
make native M=04   # нативно на Mac — нужно для урока 3 (обучение на GPU)
make lab M=04      # в Docker → http://localhost:8888
make test M=04     # проверка упражнений
```

Урок 2 скачивает ~250 МБ (две маленькие модели BERT и токенизаторы). Урок 3 дообучает модель
~10 минут на Mac M1 и в CI не выполняется. Ответы LLM в уроке 3 записаны в кассеты.
