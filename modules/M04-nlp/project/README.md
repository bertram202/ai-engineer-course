# Проект M04. LLM размечает — маленькая модель учится

## Задача

Маркетплейсу нужно раскладывать отзывы по **темам**, а не по тональности: `размер`, `качество`,
`доставка`, `продавец и возврат`, `другое`. Размеченных данных нет. Бюджет на ручную разметку — сто отзывов.
Поток — миллион отзывов в месяц, поэтому гонять каждый через LLM дорого.

Стратегия из теории: разметить тысячи отзывов с помощью LLM, дообучить на этой разметке маленькую модель
(**дистилляция**) и проверить обе на небольшом наборе, размеченном вручную.

## Требования

1. **Схема и инструкция.** Опишите 5 тем так, чтобы по описанию мог разметить человек. Отзыв может
   касаться нескольких тем — выберите главную и опишите правило выбора.
2. **Золотой набор.** Разметьте вручную 100 отзывов из `validation` RuReviews (по 20+ на тему, если
   получится). Это ваш тест, модели его не видят.
3. **Разметка LLM.** Разметьте моделью `main` 3000 отзывов из `train` со структурированным ответом по
   JSON-схеме (`enum` из 5 тем). Промпт отладьте на 20 отзывах, которые не входят ни в золотой набор,
   ни в эти 3000.
4. **Дистилляция.** Дообучите rubert-tiny2 на 3000 отзывах с метками LLM. Для сравнения обучите
   TF-IDF + логистическую регрессию на тех же метках.
5. **Сравнение на золотом наборе:** LLM, дообученный rubert-tiny2 и TF-IDF — accuracy, macro-F1,
   матрицы ошибок; время на 1000 отзывов; токены LLM на 1000 отзывов.
6. **Отчёт** `project/report.md`: схема тем, результаты, где ученик отстаёт от учителя-LLM и почему,
   сколько стоила бы обработка миллиона отзывов каждым способом (в часах работы и токенах).

## Критерии оценки

| Критерий | Баллы |
|---|---|
| Понятная схема тем и правило выбора главной темы | 1 |
| Золотой набор не участвовал ни в отладке промпта, ни в обучении | 2 |
| Разметка LLM через JSON-схему, промпт отлажен на отдельной выборке | 2 |
| Дообучение и baseline на одних и тех же метках | 2 |
| Сравнение по качеству, скорости и цене с выводами | 3 |

## Подсказки

- Ответы LLM кэшируются в `~/.cache/mlcourse/llm`: повторные запуски бесплатны.
- 3000 запросов к `main` — около часа. Запустите разметку в фоне и сохраняйте результаты на диск частями.
- Если ученик заметно хуже учителя, посмотрите на ошибки: чаще всего это темы, которые LLM размечает
  непоследовательно. Шум в метках учителя ограничивает ученика — как звёзды в RuReviews.
- Эта же схема — основа дистилляции LLM (M07, M25): большая модель генерирует данные, маленькая учится.
