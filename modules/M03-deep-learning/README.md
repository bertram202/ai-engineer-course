# M03. Нейросети, PyTorch и CV

🎯 **Цель модуля:** собрать нейросеть из знакомых деталей и освоить PyTorch — язык, на котором в следующих
модулях мы напишем трансформер и загрузим в него веса Qwen3. Компьютерное зрение — одной главой,
ровно в том объёме, в каком из него выросли идеи LLM: остаточные связи, transfer learning, ViT и CLIP.

⏱ ~8 часов · **Пререквизиты:** M01 (градиенты, Adam, softmax, кросс-энтропия), M02 (валидация, метрики).
Уроки с обучением запускайте нативно (`make native M=03`): в Docker нет GPU Apple (MPS).

## Как запустить

```bash
make native M=03   # нативно на Mac — рекомендуется: обучение идёт на GPU (MPS)
make lab M=03      # в Docker (CPU) → http://localhost:8888
make test M=03     # проверка упражнений
```

Урок 3 при первом запуске скачивает ~700 МБ (веса CLIP и ResNet-18, датасет EuroSAT) и в CI
не выполняется. Выводы в ноутбуке записаны на Mac M1.
