# Проект M03. Когда дообучение окупается

## Задача

В уроке 3 linear probe на признаках ResNet-18 (0,93) обогнал дообучение всей сети (0,89) при 300 снимках
на класс. Но на больших данных дообучение обычно выигрывает. Где точка перелома? Ответ нужен каждый раз,
когда вы решаете, дообучать ли модель — в том числе LLM (M25).

## Требования

1. Возьмите EuroSAT и отложите фиксированный тест — по 200 снимков на класс, как в уроке.
2. Для размеров обучающей выборки 50, 100, 300, 1000 и 2000 снимков на класс сравните:
   - linear probe: логистическая регрессия на замороженных признаках ResNet-18;
   - fine-tuning всей сети: раздельные шаги для головы и тела, косинусное затухание, аугментации.
     Число эпох и шаги подберите на **валидационной** части обучающей выборки, не на тесте.
3. Для каждого размера — accuracy на тесте и время обучения. Для маленьких выборок усредните по трём
   случайным подвыборкам и покажите разброс.
4. Постройте график «размер выборки → accuracy» для обоих методов и найдите, с какого размера
   дообучение надёжно (с учётом разброса) обгоняет linear probe.
5. Отчёт `project/report.md`: график, таблица, найденная точка перелома, оценка времени и 3–5 выводов.
   Что бы вы посоветовали команде, у которой 500 размеченных снимков на класс и один ноутбук?

## Критерии оценки

| Критерий | Баллы |
|---|---|
| Тест фиксирован и не используется для выбора гиперпараметров | 2 |
| Обе стратегии реализованы корректно (замороженные признаки, раздельные LR, режимы train/eval) | 3 |
| Кривые обучения с разбросом по подвыборкам | 2 |
| Точка перелома обоснована цифрами | 2 |
| Практическая рекомендация | 1 |

## Подсказки

- Признаки для linear probe считаются один раз для всех снимков — дальше только логистическая регрессия.
- Самое долгое — fine-tuning на 2000 снимков на класс: на M1 это около 10 минут на эпоху при 224×224.
  Попробуйте обучать на снимках 64×64 без увеличения — это в 12 раз быстрее — и сравните качество.
- Для малых выборок полезна ранняя остановка по валидации.
