# Датасеты

Сами данные в git не хранятся: каждый модуль скачивает их скриптом с проверкой контрольных сумм.
Для каждого датасета фиксируется лицензия — курс использует только данные,
лицензия которых допускает коммерческое использование (CC0, CC BY, Apache 2.0, MIT и т. п.).
